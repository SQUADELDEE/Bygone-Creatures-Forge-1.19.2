README FOR SQUADELDEE'S BYGONE CREATURES:
-------------------------------------------------------------------------------------------------

This is the official git repository for Squadeldee's Bygone Creatures, a mod project adding various new mobs, items, and functionality for 1.19.2. As of now, this specific project will not be updated to later versions as a result of other work and the time commitment required for other projects. The final release is a BETA including the latest in dev mobs for users to play around with. To access the published mod page, head to:

https://www.curseforge.com/minecraft/mc-mods/squadeldees-bygone-creatures

Information on how to properly use the mod can be found there!
